BLOGNEST API - START HERE

1. Install Node.js 18+ and MongoDB.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run: npm install
5. Copy .env.example to .env
6. Put your MongoDB connection string in MONGO_URI.
7. Put a JWT secret in JWT_SECRET.
8. Put your Gemini API key in GEMINI_API_KEY if you want AI features.
9. Run: npm start
10. Open Postman and import postman/BlogNest.postman_collection.json

Server: http://localhost:5000
